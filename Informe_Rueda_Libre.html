Guía de aprendizaje

Rueda Libre

Informe detallado del sitio web: qué tecnologías usamos, qué hace cada parte y cómo continuar trabajando en ella.

En pocas palabras: el proyecto está construido con HTML para el contenido y CSS para la apariencia. Las tres páginas comparten una única hoja de estilos: CSS/estilos.css.

Revisión del proyecto: 27 de octubre de 2026

1. ¿Qué construimos?

Rueda Libre es un sitio web pequeño para presentar un servicio de alquiler de bicicletas. Tiene tres páginas conectadas entre sí: Inicio, Tarifas y rutas, y Reserva. El contenido y el diseño están separados: el HTML describe qué aparece y el CSS define cómo se ve.

ParteArchivoResponsabilidad

Inicioindex.htmlPresenta el negocio, sus servicios, cómo alquilar, ubicación y contacto.
Tarifas y rutaspaginas/tarifas.htmlMuestra precios, recorridos y galerías de bicicletas por categoría.
Reservapaginas/reserva.htmlPresenta el formulario para ingresar datos y una fecha y hora solicitadas.

No se está usando un framework (como Bootstrap o React), JavaScript ni un servidor para procesar reservas. Es un sitio estático hecho con HTML y CSS.

2. Cómo se conectan HTML y CSS

Cada página incluye la hoja de estilos dentro de <head> con una etiqueta <link>. La página de Inicio está en la carpeta principal, pero Tarifas y Reserva están dentro de paginas/; por eso sus rutas suben una carpeta usando ../.

<!-- index.html -->
<link rel="stylesheet" href="CSS/estilos.css">

<!-- paginas/tarifas.html y paginas/reserva.html -->
<link rel="stylesheet" href="../CSS/estilos.css">

La ruta se cuenta desde la ubicación del propio HTML. Si se mueve una página o el CSS, hay que corregir el href; si no, el navegador no encontrará los estilos.

Las hojas anteriores reserva.css y tarifas.css se reunieron en estilos.css. El archivo está separado por comentarios en estilos base, Reserva, Inicio y Tarifas. Esto permite mantener un único lugar para los estilos y distinguir qué bloque corresponde a cada página.

En el estado actual, Inicio y Tarifas no tienen una imagen o un color de fondo propio en el body; usan el fondo normal del navegador. Reserva conserva el degradado suave que ya tenía. Componentes concretos, como la navegación, el mensaje de bienvenida y el encabezado de Tarifas, sí tienen sus propios fondos.

3. Conceptos básicos del CSS usado

Selector: a quién se aplica una regla

  • body selecciona la página completa.
  • .tarifa-card selecciona cualquier elemento que tenga class="tarifa-card". El punto indica una clase.
  • #recorridos selecciona el elemento que tiene id="recorridos". El numeral indica un identificador único.
  • .servicio-card > img selecciona las imágenes que son hijas directas de una tarjeta de servicio.

Las clases se pueden repetir para dar el mismo diseño a varias tarjetas. Un id identifica una sección concreta y también permite enlazar directamente a ella con una dirección como tarifas.html#recorridos.

La caja de un elemento

En una tarjeta, padding es el espacio interior entre el borde y el contenido; border es el contorno; margin separa esa tarjeta de otros elementos. La regla global box-sizing: border-box hace que el ancho declarado incluya el relleno y el borde, lo que facilita calcular tamaños.

Unidades y tamaños flexibles

  • px: cantidad fija de píxeles, útil para bordes y separaciones pequeñas.
  • %: proporción respecto al tamaño del contenedor.
  • rem: tamaño relativo al tamaño de letra raíz; ayuda a escalar texto.
  • clamp(mínimo, preferido, máximo): permite que un tamaño crezca o disminuya sin salir de límites.
  • min() y calc(): combinan medidas para limitar anchos y calcular columnas.

4. Página Inicio: index.html

Inicio tiene una barra de navegación con el logo, el nombre Rueda Libre y enlaces a las otras páginas. Debajo hay un mensaje de bienvenida y una fila de tres contenedores: Alquiler de bicicletas, Nuestros servicios y Quiénes somos. Luego aparecen «También te ofrecemos» (Rutas guiadas y Taller básico), los pasos para alquilar, la ubicación y el pie de contacto.

El mensaje de bienvenida usa un header con un encabezado y un párrafo, y las tarjetas principales están agrupadas en una sección etiquetada. «También te ofrecemos» también está agrupado como sección con nombre accesible.

Distribución de las tres tarjetas

La clase .presentacion-grid usa CSS Grid con tres columnas. Cada columna tiene un mínimo de 210 píxeles y puede crecer; gap deja espacio entre ellas. Si la pantalla es estrecha, overflow-x: auto permite desplazarse horizontalmente para ver el contenido sin comprimir las tarjetas.

Enlaces con apariencia de botón

«Consulta las tarifas de alquiler» y «Ver recorridos y precios» son enlaces HTML con aspecto de botón creado con CSS. Siguen navegando a otra página o sección; el estilo no cambia su función. La ubicación también ofrece un enlace a Google Maps.

Tarjetas y pasos

.contenido-card da un fondo blanco, borde redondeado y sombra suave a las secciones principales. Los pasos de alquiler usan una lista ordenada; CSS muestra números dentro de círculos para que se lean como una secuencia.

5. Página Tarifas: paginas/tarifas.html

Contiene dos tablas: tarifas de alquiler (por hora, medio día y día completo) y recorridos guiados (distancia, duración, nivel y precio). Los identificadores tarifas y recorridos permiten que un enlace lleve directamente a una de esas tablas.

Cada tabla está en su propia sección, con un título y un caption descriptivo. Los nombres de bicicleta y recorrido son encabezados de fila (th scope="row") y los encabezados de columna usan scope="col".

Como contenido complementario, un aside reúne lo que incluyen las tarifas, el horario de salida de los recorridos y la lista «Qué llevar». Después aparecen tres categorías de bicicletas: urbanas, de montaña y eléctricas. Cada galería es una lista ul con tres elementos li e imágenes con descripciones alternativas (alt).

  • En pantallas anchas, las tarjetas procuran ocupar tres columnas.
  • Hasta 700 píxeles de ancho, pasan a dos columnas.
  • Hasta 480 píxeles, se muestran en una columna.
  • object-fit: contain muestra la imagen completa dentro de un marco de altura fija, sin recortar la bicicleta.

Las reglas @media son consultas de medios: aplican estilos solo cuando la pantalla cumple una condición de tamaño. Se usan para que la página funcione tanto en computadores como en teléfonos.

6. Página Reserva: paginas/reserva.html

El formulario tiene campos de nombre, correo, teléfono, fecha, hora y duración. Cada label nombra su campo y se conecta mediante for con el id del control. Esto facilita identificar los campos, incluso con lectores de pantalla. La fecha, hora y duración comparten un fieldset con legend, porque forman un grupo relacionado.

Tipo de campoQué permite escribir o elegir
textNombre de la persona.
emailCorreo; el navegador puede revisar que tenga formato de correo.
telNúmero telefónico.
date y timeFecha y hora con los controles disponibles en el navegador.

required marca campos obligatorios. El navegador muestra un aviso y evita enviar el formulario si falta un valor válido. La clase .isla diseña la tarjeta blanca del formulario; .fondo centra el contenido y aplica el degradado suave de Reserva.

El horario de atención se presenta aparte del formulario dentro de un aside: de lunes a viernes, de 7:00 a. m. a 5:00 p. m.

Importante: actualmente el formulario es visual y tiene validación básica del navegador, pero no registra ni envía una reserva a un negocio. El formulario usa action="#"; para guardar o enviar datos hace falta conectar un servidor o un servicio de formularios, además de definir cómo proteger y gestionar esos datos.

7. Interacciones y accesibilidad

  • :hover cambia el aspecto al pasar el cursor sobre un botón o enlace.
  • :focus-visible dibuja un contorno cuando se llega al enlace usando el teclado. Ayuda a saber dónde está el foco.
  • :active representa el momento en que se pulsa un enlace o botón.
  • Los textos alt describen las imágenes si no se cargan y ayudan a tecnologías de asistencia.
  • Los encabezados, las secciones, las tablas y las etiquetas del formulario comunican la estructura además de la apariencia.

Cuándo conservar un contenedor genérico

En las páginas del sitio se conservaron algunos div únicamente para agrupar elementos para el diseño: el contenedor interno de la navegación, los bloques de texto dentro de tarjetas de servicios y cada grupo visual de etiqueta con su campo del formulario. No representan secciones o contenidos independientes, así que usar section, article o fieldset en esos casos daría una semántica incorrecta. La bitácora del proyecto registra estos motivos. En cambio, la bienvenida, las galerías, los datos relacionados del formulario y el contenido complementario usan elementos semánticos.

8. Cómo hacer cambios habituales

Cambiar un texto

Busca el texto en el HTML correspondiente y edítalo allí. Por ejemplo, para cambiar el título de la página Tarifas, edita el <h1> de paginas/tarifas.html. El CSS decide cómo se presenta; el HTML contiene las palabras.

Cambiar una imagen

  1. Guarda la imagen dentro de la carpeta img/.
  2. En el HTML, cambia el atributo src para que coincida exactamente con el nombre y la extensión.
  3. Actualiza el texto alt para describir la imagen nueva.
  4. Recarga la página y comprueba que la imagen aparece.

Desde una página dentro de paginas/, la ruta empieza con ../img/; desde index.html, empieza con img/. Mayúsculas, espacios y extensiones como .jpg o .jpeg deben coincidir.

Cambiar el diseño

Busca en CSS/estilos.css la clase que aparece en el HTML. Por ejemplo, tamaños de tarjetas de bicicletas están en .bicicleta-card; los fondos de páginas o tarjetas están en las reglas de las clases correspondientes. Cambia una propiedad a la vez y revisa el resultado en el navegador.

10. Glosario breve

  • HTML: lenguaje que organiza el contenido de una página.
  • CSS: lenguaje que da estilo y distribución al contenido.
  • Etiqueta: elemento HTML, como <p> para un párrafo o <img> para una imagen.
  • Atributo: información extra dentro de una etiqueta, como src, href, class o alt.
  • Clase: nombre reutilizable para identificar elementos que comparten estilo; se escribe con punto en CSS.
  • Identificador (id): nombre de un elemento concreto; se escribe con numeral en CSS y sirve como destino de un enlace.
  • Responsive: diseño que se acomoda a distintos anchos de pantalla.
  • Backend: parte del sistema que recibe, valida y guarda información en un servidor.

Resumen final

Lo que quedó es un sitio estático de tres páginas, construido con HTML y una hoja CSS unificada. HTML contiene títulos, texto, navegación, galerías, tablas y formulario; CSS controla su presentación, distribución, adaptación a móviles y estados interactivos. Las imágenes se guardan en img/. Para seguir aprendiendo, lo más práctico es cambiar un texto, una imagen o una propiedad CSS pequeña, recargar el navegador y observar qué efecto tuvo.

Este informe describe los archivos tal como se revisaron en el proyecto; no afirma que el formulario de reserva guarde datos.
